---
description: Perform a product-quality UI polish pass.
---

Inspect the existing UI against docs/09-ui-ux.md and docs/10-design-system.md.

Fix only:
- spacing inconsistency;
- typography hierarchy;
- poor empty/loading/error states;
- unclear primary actions;
- accessibility issues;
- awkward responsive behavior;
- excessive visual noise;
- missing feedback;
- inconsistent component variants.

Do not add new product scope.
Do not introduce decorative animations.
Run browser and accessibility tests afterward.
